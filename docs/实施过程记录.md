## 2026-04-27 — 方向 H H5：Auto-Memory + Draft Rewrite + Ask 联动 + Skill 模板变量（Claude）

- 背景：H4 验证通过后，用户选定 B→A→C→D 顺序实施 H5 四项功能。
- 本轮完成项：
  - **H5-B：审批后自动提炼全局记忆**
    - `approve_agent_draft_impl` 写盘后异步调用 `extract_and_save_memories_from_draft`
    - LLM 从草稿内容提炼 3-5 条 `key: value` 全局记忆，upsert 到 `agent_memories`（run_id=None）
    - 事件日志记录提炼数量；LLM 不可用时静默降级
  - **H5-A：基于批注重写草稿**
    - 新增 `rewrite_agent_draft_impl(draft_id, comment)`：原草稿（6000字）+ 批注 → LLM → 新草稿记录
    - 新增 Tauri 命令 `rewrite_agent_draft`，120s 超时（LLM 重写耗时较长）
    - 前端草稿头增加"批注重写"输入栏，Enter 触发，生成后自动选中新草稿
  - **H5-C：Ask 联动（ask_first）**
    - `generate_agent_draft_impl` 新增 `ask_first: bool` 参数
    - ask_first=true 时先调 `query_ask_with_options(top_k=3)` 获取现有知识库答案（≤1200字），注入生成 prompt
    - 前端 composer 新增"Ask 联动"勾选框；事件消息加 `ask: on` 标记
  - **H5-D：Skill 模板变量**
    - Skill prompt 支持 `{{topic}}` / `{{memories}}` 占位符，生成时自动展开
    - `memories_context` 整体替换到 `{{memories}}`，`topic` 替换到 `{{topic}}`
  - 前端 `tauri-client.ts`：`generateAgentDraft` / `createGenerateAgentDraftArgs` 新增 `askFirst/ask_first` 双键；`rewriteAgentDraft` 函数（120s 超时）
  - 测试：`app-utils.test.ts` 更新 `createGenerateAgentDraftArgs` 断言含 `researchMode`
- 提交：
