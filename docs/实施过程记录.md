## 2026-04-13 摄入/查询按钮卡住修复（subagents 并行）

  - `handleDemoIngest` 与 `handleQueryAsk` 在设置 loading 状态后，先在 `try` 外执行 `await listenProgress(...)`。

    - 订阅失败仅 `console.warn`，不阻断主流程。
    - `finally` 中仅在 `unlisten` 存在时调用，确保状态总能复位。
