## 2026-04-24 — 方向 A 测试修复：localStorage mock 与业务代码对齐（Claude Code）

- 背景：
  - Codex 修复"最近 Vault 路径"测试失败时，将 `installLocalStorageMock()` 注入测试，但仍失败。
  - 根本原因：业务代码 `readRecentVaultPathsFromStorage` / `writeRecentVaultPathsToStorage` 使用 `window.localStorage` + `typeof window === "undefined"` 守卫。vitest 测试环境为 Node（无 jsdom），`window` 不存在，函数提前返回 `[]`，mock 设在 `globalThis.localStorage` 但业务代码读不到。
- 修复：
  - `web/src/App.tsx`：将两个函数改为使用 `globalThis.localStorage` + `if (!storage)` 守卫，与项目内其他存储函数（`readWikiSortModeFromStorage` 等）保持一致。
  - `web/src/app-utils.test.ts`：保留 `installLocalStorageMock()` 调用（mock 现在可被业务代码读到）。
- 验证：
  - `npm --workspace web run test -- --run`：160/160 通过 ✅
  - `npm --workspace web run typecheck`：0 errors ✅
  - `cargo test`（src-tauri/）：160/160 通过 ✅
