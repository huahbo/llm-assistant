**C1.4** — `agent_chat` 模块：DB schema（conversations/messages/tools 三张表）+ CRUD + 内置工具种子（search_wiki/read_wiki/write_wiki/run_shell/web_search/fetch_url）。

### C2：后端 ReAct 主循环

**C2.1** — `agent_chat/tools.rs`：工具执行分发器（按 tool_name 路由到各 exec_* 函数）。

**C2.2** — `agent_chat/stream_parser.rs` + `commands.rs`：ReAct 主循环（多轮 LLM→工具→观察），流式 Tauri 事件 emit（`chat_text_delta/chat_tool_call/chat_tool_result/chat_message_done`）。`reasoning_content` 静默累积并存 DB（不 emit）。

**C2.3** — Tauri 命令注册：`send_chat_message/cancel_chat_message/get_conversations/get_messages`。

### C3：前端流式 UI

**C3.1** — `web/src/types.ts` 对话相关类型 + `tauri-client.ts` 命令封装。

**C3.2+C3.3** — `MessageBubble.tsx`（工具卡/流式 cursor/Markdown渲染）+ `useChatStream.ts`（reducer 驱动的流式状态机）+ 路由集成到主导航。

### C4：对话管理功能

**C4.1** — 自动生成对话标题（首条用户消息发出后，后台调 LLM 生成标题）。

**C4.2** — Skill 模板 + 记忆注入（与 Agent Studio 共享 ShellPolicyContext 数据源）。

## H9-C — 工具卡片折叠 + 重复消息修复（2026-05-11）

### ToolGroup 折叠组件

- `MessageBubble.tsx`：所有工具调用卡片合并为单个 `ToolGroup` 折叠组。
  - 默认收起；工具运行中或等待审批时自动展开；完成后显示 `N/M 完成 · Xms`。
- `styles.css`：`.chat-tool-group` 系列样式。

### 重复消息根因修复

- **根因**：ReAct 多轮迭代中，每轮创建新的 DB assistant 占位消息（不同 `message_id`）。原 `useChatStream.ts` reducer 的 `message_id` 固定在首个事件的 ID，末轮消息过滤失效，导致流式气泡与 DB 消息同时显示。
- **修复**：`TEXT_FLUSH` 和 `TOOL_CALL_START` 两个 reducer 分支均实时更新 `message_id: action.messageId`，始终跟踪最新一轮的 ID。
- **空行消失**：DB 中工具调用迭代产生的 `content=null` 助手消息，在 `MessageBubble` 渲染时提前 `return null`（非取消状态下）。
- 提交：`1c42f33`
