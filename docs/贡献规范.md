# 贡献规范（提交与分支）

## 1. 分支命名
- `main`：稳定主线
- `feat/<topic>`：新功能（示例：`feat/query-topk`）
- `fix/<topic>`：缺陷修复（示例：`fix/log-refresh`）
- `chore/<topic>`：工程维护（示例：`chore/gitignore-cleanup`）
- `docs/<topic>`：文档更新（示例：`docs/technical-design-cn`）

## 2. Commit 约定
建议使用 Conventional Commits：
- `feat: ...` 新功能
- `fix: ...` 修复
- `chore: ...` 工程杂务
- `docs: ...` 文档
- `refactor: ...` 重构（不改行为）
- `test: ...` 测试

示例：
- `feat(query): support top_k options for ask command`
- `fix(ui): refresh logs after query ask`
- `chore(repo): normalize workspace lockfile`
- `docs(architecture): update v1 interface contract`

## 3. 提交粒度
- 一个 commit 只做一个主题。
- 代码变更和文档变更可拆成两个 commit，便于回滚与审阅。
- UI 大改建议拆分为“样式”和“逻辑”两个 commit。

## 4. 提交前检查
在 Windows PowerShell 执行：

```powershell
Set-Location E:\llm-wiki
npm --workspace web run test
npm --workspace web run typecheck
Set-Location E:\llm-wiki\src-tauri
cargo test
```

## 5. 常用流程（PowerShell）

```powershell
Set-Location E:\llm-wiki
git checkout -b feat/<topic>
git add -A
git commit -m "feat(<scope>): <summary>"
git push -u origin feat/<topic>
```

## 6. 本项目忽略项提示
避免提交本地运行与私有数据：
- `.runtime/`
- `src-tauri/.runtime/`
- `vault/`
- `node_modules/`
- `web/node_modules/`
- `src-tauri/target/`
