# 测试与验证规范

## 1. 目标
- 确保每轮开发有自动化测试兜底。
- 确保用户可在 Windows 环境通过 PowerShell 复现验证。

## 2. 自动化测试要求
- 前端变更：
  - 至少覆盖新增的状态逻辑或数据转换逻辑。
  - 提供可在本地执行的测试命令。
- 后端变更：
  - 至少覆盖新增状态流转、模式切换、数据写入关键路径。
  - 提供可在本地执行的测试命令。

## 3. 手动验证要求
- 每轮结束提供“Windows PowerShell 验证命令清单”。
- 清单至少包含：
  - 环境准备命令
  - 启动命令
  - 核心功能验证步骤
  - 结果检查命令

## 4. 完成判定
- 自动化测试通过。
- 用户按 PowerShell 步骤验证并回传结果。
- 实施过程记录已补齐测试与手动验证结果。
