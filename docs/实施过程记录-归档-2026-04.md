## 2026-04-22 — SearXNG Windows 启动脚本健壮性修复 (Codex)

- 背景：
  - 用户在 PS7 执行 `run_searxng_windows.ps1 -Recreate` 后，`verify_searxng_windows.ps1` 报错：
    - `Exception calling "GetResult" with "0" argument(s): "An error occurred while sending the request."`
  - 旧脚本问题：
    - `run` 脚本未等待容器就绪，且未检查子脚本退出码；
    - `verify` 脚本异常信息过于抽象，难以定位是容器未就绪、端口不可达还是容器启动失败。
- 修复：
  - `scripts/verify_searxng_windows.ps1`
    - 新增异常链路展开函数 `Get-ExceptionChainText`，输出 inner exception 细节。
    - `Invoke-JsonNoProxy` 对 `SendAsync().GetResult()` 加强捕获，明确输出 URL + 请求错误原因。
  - `scripts/run_searxng_windows.ps1`
    - 新增容器就绪等待：`Wait-SearxngReady`（轮询 `docker inspect` + 本地 HTTP 探测）。
    - 新增命令退出码校验：`Ensure-CommandSucceeded`。
    - 增加失败回退：推荐配置启动失败时，自动回退镜像默认配置再试一次。
    - 若自检失败，打印 `docker logs --tail 120` 并返回非零退出码。
