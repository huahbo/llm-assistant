## 目标

将 URL 内容抓取能力从零散的 `ingest_service.rs` 临时实现，重构为可复用的独立服务模块 `src-tauri/src/browser/`，同时暴露 Tauri 命令 `fetch_url_context`，供 Agent 对话的**页面摘要卡片**功能使用。

两处复用同一模块，不重复造轮子：
1. **摄入流程**（`ingest_service.rs`）：URL 摄入时调用 `crate::browser::fetch_url()`
2. **Agent 对话**（`ChatInputBar.tsx`）：粘贴 URL → 弹出确认 → 卡片插入 → 发送时注入上下文

---

## 技术选型

| 项 | 选择 | 原因 |
|----|------|------|
| Rust CDP 库 | `headless_chrome = "1.0"` | 2.9k ★ 活跃，auto-detect Chrome/Edge，API 简单 |
| 调用方式 | `tokio::task::spawn_blocking` | headless_chrome 是同步 API |
| 浏览器优先级 | Chrome → Edge → 静态 HTTP | Chrome CDP 文档最齐，Edge 同引擎兜底 |
| HTML 提取 | 移植现有 `html_to_text()` | 已验证可用，正则清洗 |
| 静态兜底 | reqwest（已有依赖）| Chrome/Edge 均找不到时降级 |

## 接口契约（Agent 间共享基准，禁止自行修改）

### Rust 后端 — `src-tauri/src/browser/mod.rs`

```rust
// 公开类型
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct FetchResult {
    pub title: String,
    pub text: String,
    pub url: String,
    pub domain: String,
    pub char_count: usize,
    pub fetch_method: String, // "cdp_chrome" | "cdp_edge" | "static_http"
}

#[derive(Debug, Clone)]
pub struct FetchOptions {
    pub timeout_secs: u64,
    pub virtual_time_budget_ms: u32,
}
impl Default for FetchOptions {
    fn default() -> Self { Self { timeout_secs: 30, virtual_time_budget_ms: 5000 } }
}

// 主入口（pub async fn）
pub async fn fetch_url(url: &str, options: FetchOptions) -> Result<FetchResult, String>;

// 供 ingest_service 复用（pub(crate)）
pub(crate) fn html_to_text(html: &str) -> String;
```

## 风险与降级策略

| 风险 | 降级 |
|------|------|
| Chrome/Edge 均未安装 | 静态 HTTP reqwest 兜底，显示 `fetch_method: "static_http"` |
| CDP 连接超时（>30s） | tokio::time::timeout 截断，自动 fallback 静态 |
| headless_chrome 与 tokio 运行时冲突 | spawn_blocking 隔离同步调用 |
| 页面需要登录 | 静默拿到登录页内容，char_count 低时 summary 会反映，用户可手动移除卡片 |
