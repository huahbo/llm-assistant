# LLM Wiki Desktop（A+C）

本项目用于实现一个 Windows 优先的个人 Wiki 桌面应用，核心路线是：

- A：本地优先应用架构（Tauri + React + SQLite + Markdown Vault）
- C：隐私兼容本地 AI 路径（Ollama + Strict Local Mode）

## 当前阶段

当前处于第 1 轮：项目骨架与接口契约搭建。

## 开发约束

- 目标运行平台：Windows（MSI/EXE 安装版）
- 代码新增注释使用中文（必要且简洁）
- 关键实施过程记录在 `docs/实施过程记录.md`
